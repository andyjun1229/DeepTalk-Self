# 用户反馈与优化记录（2025-08-05）

真实用户（VPS Linux 环境，MiniMax M3 模型）完成 9+ 小时全 63 题访谈后的反馈。
按优化排期顺序记录，含已实施和计划中的改动。

## 反馈 1：语音输入

> "整个访谈时间非常长。建议增加语音输入选项，把语音转文字，让大模型在后台识别反馈。打字没有语音自然。"

**方案：** 浏览器原生 Web Speech API（Chrome/Safari 免费支持中文）
- 自由输入区底部加 🎤 按钮
- 点击开始录音 → 实时转文字填入 textarea → 可编辑后提交
- 录音中按钮红色脉冲动画 `animate-pulse`

**实现：** `app/interview/page.tsx` — `SpeechRecognition` 初始化（`lang: "zh-CN"`），`interimResults: true`

**注意：** 仅 Chrome/Safari 支持，Firefox 不支持。不支持时不显示按钮。

---

## 反馈 2：恢复链接

> "网页版只有复制 ID 的功能，用户不知道怎么样再次进入。建议给用户一个完整链接。"

**根因：** 旧版琥珀色提示条只显示裸 UUID + "在进度页粘贴这个 ID 就能找回"。实际恢复路径是 `?recover=xxx`，但用户不知道要自己拼 URL。

**方案（三层覆盖）：**
| 改动 | 位置 | 效果 |
|---|---|---|
| 访谈页提示条：裸 ID → 完整 URL | `interview/page.tsx` | `https://pu.zj.cn/interview?recover=<sessionId>` 一行可复制 |
| 「复制恢复链接」按钮 | 同上 | 一键复制完整 URL |
| 首页「继续访谈」入口 | `page.tsx` | 检测 localStorage 中的 sessionId，自动显示绿色提示条 + "继续访谈"按钮（URL 已带 `?recover=`） |

**教训：** 任何依赖用户自己拼 URL 的恢复机制都是坏的。系统必须替用户构造完整 URL。

## 反馈 3：总结质量

> "总结部分直接粘贴用户原话，没有提炼升华。一句话说明出现语意不连续。"

**根因：** profile 生成提示词写了「引用用户原话佐证」，LLM 理解成大量直接粘贴。

**方案：** 重写 `app/api/profile/generate/route.ts` 系统提示词：

```
旧：「引用用户原话佐证」
新：「提炼用户的核心模式，用自己的话总结。只在关键判断处引用一句原话（≤20字），不要大段粘贴。」
```

新增三条核心原则：
1. **提炼，不要粘贴** — 用你自己的话总结
2. **找模式，不是列事实** — 找规律、矛盾、重复出现的模式
3. **先判断，后佐证** — 先写一句提炼性判断，再用一句原话佐证

每个维度示例格式：「你在决策时更依赖直觉而非数据，但你的直觉来自大量实践经验的积累」→ 一句原话佐证 ≤20 字。

## 反馈 4：隐私

> "用户内容默认不留存在服务器上。建议生成完整文件让用户自我保存，需要时上传。给用户选择权。"

**方案（三层）：**
| 功能 | 实现 |
|---|---|
| 📥 下载访谈记录 | `GET /api/session/export` — 按维度分组的 Markdown 文件，浏览器直接下载 |
| 🗑 删除我的数据 | `DELETE /api/session` — 清空 answers + progress + progress_backups，二次确认弹窗 |
| 说明 | 访谈完成页底部新增两个按钮，隐私声明更新 |

**不改：** 不改成默认不存服务器——会破坏进度恢复。给用户选择权：可导出后删除。

---

## 反馈 5：模型分层

> "免费版可以用 Agnes AI，收费版用更好的模型。"

**调研结果：** Agnes AI 域名（`agnesi.ai`、`agnes.chat`、`agcn.ai`）全部 DNS 不解析——服务不可用或已关停。

**替代方案：**
| 层级 | 模型 | 状态 |
|---|---|---|
| 免费版 | MiniMax M3 | 已部署，优化过的 prompt |
| 付费版 | DeepSeek V4 Pro | 已配置，profile 生成用此模型 |

追问逻辑是规则引擎驱动（`decide()`），不依赖模型质量，两层差距主要在总结生成。
