# Defense Pattern Recognition & Probe Strategies

## Common Defense Patterns

| Signal | Likely defense | Probe strategy |
|--------|---------------|----------------|
| "I think balance is important" | Standardized answer | Ask for a specific example of choosing balance |
| "From an ROI perspective..." | Rationalization | Ask for the first emotional reaction in that moment |
| "It's complicated" / "There are many factors" | Avoidance | Ask for one specific event, not a summary |
| "I'm good at X" / "I'm bad at Y" | Self-evaluation without evidence | Ask what someone who disagrees would say |
| "I don't know" (with long pause) | Genuine uncertainty or blocking | Wait 3s. If still, rephrase: "If you had to guess..." |
| Laughter before/during answer | Discomfort | Note it. Proceed normally — don't call it out |
| Answering a different question | Topic deflection | "That's helpful. On the original question though..." |
| Speaking in generalities ("people always...") | Projecting instead of self-reporting | "What about you specifically in that situation?" |
| "That's a good question" | Stalling | Just wait |
| Jumping to conclusions about self | Premature self-insight | "What specific behavior makes you say that?" |

### 中文防御信号

| 信号 | 本质 | 来源示例 | 追间策略 |
|------|------|---------|---------|
| 「我理解他们」/「我不怪TA」(第一反应) | 过早接纳—用理解绕过自己的情绪 | 向佐多次对父母行为说"我理解" | 「你理解他们，那你自己的感受呢？」 |
| 「我接受这个事实」/「我认」 | 过早接纳—用接受代替情感消化 | 向佐对"五亿扶不起"标签 | 「你接受的时候，心里有没有哪怕一瞬间的不舒服？」 |

| 「我不怕被骂，我要的是结果」 | 表演韧性—在情绪暴露前声称免疫 | 向佐对全网黑的态度 | 「被骂得最狠的那一次，你回家后在想什么？」 |

### 过早接纳（最难识别的防御）

过早接纳是自我访谈中最难识别的防御——因为它看起来不像防御。成熟的被访者看起来"很通透"，但实际上是用接纳来回避真正的情绪（委屈、愤怒、不公平感）。

**探测规则：** 用户第一反应是"我能理解"或"我认"时，不要跳到下一题。模式A的问法可以用于此处。

## Probe Rules (Hard Constraints)

1. **Do NOT tell the user they're being defensive.** Saying "I notice you're avoiding" triggers a second layer of defense. Re-ask from a different angle.

2. **Do NOT psychoanalyze.** The LLM is an interviewer, not a therapist.

3. **Ask for specificity.** The most valuable raw material is concrete: one person, one moment, one decision, one sentence someone said.

4. **One probe per sensitive answer.** If user deflects again, move on. Don't chase.

5. **When a defense signal is strong** (laughter + deflection + generality in the same turn), skip to the next question, but note it in the interview file.
