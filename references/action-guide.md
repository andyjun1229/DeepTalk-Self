# 行动指南系统 V2

## 概述

访谈完成后（63 题 → LLM 生成 profile），进入第二阶段：从自我画像到可执行行动。

**核心设计：四套哲学体系 × 七维度，各自分工不重叠。**

## 四体系分工

| 体系 | 解决什么问题 | 对位维度 |
|------|-------------|---------|
| 易经 ☯ | 「我不知道现在处于什么阶段、该进还是该退」 | D1 决策逻辑、D6 能力图谱 |
| 王阳明心学 🫀 | 「我知道但做不到」 | D3 学习成长、D5 防御机制 |
| 道德经 🌊 | 「我太用力了、越用力越糟」 | D4 价值观动机、D5 防御机制 |
| 儒家 📜 | 「我在关系中找不到位置」 | D2 人际交往、D7 家庭身份 |

## 匹配逻辑

从 LLM 生成的 profile 文本中，用关键词匹配识别每个维度的信号模式。每个体系只匹配最严重的一个维度，确保四张卡不重叠。

触发关键词库（例）：
- 易经: `avoid`, `mismatch`, `impulse`, `external`
- 王阳明: `know_but`, `perfect`, `rationalize`, `accept_early`
- 道德经: `control`, `conflict`, `external_drive`, `overreach`
- 儒家: `expectation`, `role_conflict`, `avoidant`, `dependent`

## 每张行动卡结构

```
处境诊断 → 哲学镜照 → 本周一事 → 检验信号
```

- **处境诊断**：从画像中提取的具体模式
- **哲学镜照**：用该体系的经典框架重新框定问题（含原文引用）
- **本周一事**：可操作的、具体的、不超过 30 分钟
- **检验信号**：你怎么知道有变化了

## 技术实现

- **规则引擎**：`app/lib/engine/action-guide.py` — 纯 Python，零 LLM 依赖
- **API 路由**：`/api/action-guide/generate` — 传入 sessionId，自动拉回答→LLM 生成 profile→引擎生成卡
- **前端**：CompletePanel 组件（interview/page.tsx），状态机：按钮 → loading → 四张卡

## 模板示例（易经·需卦）

```
处境：D1 显示用户逃避决策，反复推迟
镜照：等待是对的，但别把等待当逃避。需卦：坎水在上，乾天在下——云在聚集了。
行动：列出 3 件「等时机」的事，选一件今天做第一步。
信号：做完第一步后，对「时机」的感觉有没有变化？
```
