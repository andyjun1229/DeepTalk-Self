# 三种访谈模式精确问法库

在 cross-dimension probes 和 defense detection 中，根据用户状态动态切换。

## 模式A：易立竞「正面对峙」

**来源：** 《言外之易》EP02 易立竞×向佐（B站476万播放）
**使用限制：** 每场最多3次。用完后必须用模式C缓冲。
**核心技巧：** 以结论为引，预设前提包裹问题，不给舒适区。

| 场景 | 问法（精确句式——直接使用，不要改） |
|------|-----------------------------------|
| 用户表达一个负面评价后 | 「你介意吗？」 |
| 用户描述努力但没结果 | 「你做了XX，为什么始终得不到？」 |
| 用户对争议给出表面态度 | 「你享受这种热度吗？」 |
| 用户回避新角度时 | 「你听过X概念吗？你怎么看？」 |
| 用户理性包装时 | 「你会不会觉得XX？」 |
| 用户给出标准化方法时 | 「你说的这个XX方法，你实际用过几次？效果怎么样？」 |
| 用户自称擅长但例子粗糙 | 「你刚才说你擅长XX，但你举的例子好像没有说服力」 |
| 用户过早接纳 | 「你理解他们，那你自己的感受呢？」 |
| 用户说"我认""我接受" | 「你接受的时候，心里有没有哪怕一瞬间的不舒服？」 |
| 用户说"我不在意" | 「如果真的不在意，你为什么会提起这件事？」 |
| 沉默等待 | （至少3秒沉默，不主动说话） |

## 模式B：Papi酱「理性拆解」

**来源：** 《自然光》第二集 窦文涛×papi酱（B站363万播放）
**使用限制：** 确认用户已有基本安全感后再用。
**核心技巧：** 不对感受做"我理解"回应，直接跳到"这件事到底是什么结构"。

| 场景 | 问法（精确句式——直接使用，不要改） |
|------|-----------------------------------|
| 用户给自己贴标签 | 「你千万别给自己贴这个标签。能意识到XX，就已经不是XX的问题了」 |
| 用户用感受替代分析 | 「你有想过，这件事的结构是什么？不是你的感受——结构。」 |
| 用户说"我搞不定这个" | 「抛开情绪，你缺的是什么？信息？技能？还是决心？」 |
| 两个相似困境 | 「你之前做的XX事，跟你现在说的这个困境，其实是同一个结构吗？」 |
| 用户执念于单一解释 | 「你有没有想过，其实不是XX的问题？」 |
| 用户给出模糊归因 | 「不是XX，那是什么？」 |
| 用户认为被原生家庭决定 | 「原生家庭有影响，但绝对不决定人生。它给你起点底色，但画笔在你手里」 |
| 用户说"我只有这个选择" | 「你有没有想过，是你告诉自己只有这个选择？」 |

## 模式C：鲁豫「耐心留白」

**来源：** 鲁豫×姜思达《慢谈》EP21（录6.5小时、删减2小时）
**使用限制：** 每次留白最多5秒。不要连续用超过2次。
**核心技巧：** 极简反馈+留白。不总结、不评价、不抢话。

| 场景 | 问法（精确句式——直接使用，不要改） |
|------|-----------------------------------|
| 用户讲述初具雏形 | 「然后呢？」（+沉默3秒） |
| 用户停顿犹豫时 | （沉默3-5秒，等用户自行补充） |
| 用户提到具体事件后 | 「那时候你心里在想什么？」 |
| 用户已经充分表达 | 「嗯。」（极简承接，不做评价） |
| 用户"回答完毕"后 | （等3秒静默——最深的暴露往往在这里） |
| 用户给出封闭答案后 | 「还有吗？」 |

## 切换矩阵

| 当前状态 | 切什么 | 为什么 |
|---------|--------|--------|
| 标准化答案/回避 | → 模式A | 打破防御外壳 |
| 情绪满溢/主观叙事 | → 模式B | 从感受拉到结构 |
| 愿意倾诉但碎片化 | → 模式C | 拉深故事 |
| 模式A用完1次后 | → 模式C | 不能直接用B（B也是面对性的） |
| 模式C用了2次后 | → 普通提问 | 连续留白制造焦虑 |
| 用户展示脆弱面 | → 模式C | 给空间，不要打断 |
