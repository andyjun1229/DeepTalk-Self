# DeepTalk Self — 深度自我访谈框架 v3.0

**让AI像顶级访谈主持人一样，帮你拆解自己。**

> 不是心理测试。是结构化、有方法的深度自我对话。

---

## 这是什么

DeepTalk Self 是一套**结构化深度自我访谈系统**。核心思路不是设计"更好的问题列表"，而是让AI学会顶级访谈主持人的追问逻辑——不评判、不打断、不怕得罪人，通过结构化追问帮你拆解自己的决策模式、人际盲点、价值观和深层动机。

v3.0 版本基于对三篇真实访谈实录（易立竞×向佐、窦文涛×papi酱、鲁豫×姜思达）的拆解，升级为 **7维度 × 63题** 的完整框架，含三种访谈模式切换、防御模式识别、进度管理和自动画像生成。

## 核心特色

### 1. 7维度交叉验证

不是线性问答，是从7个不同角度反复验证同一个人：

| 维度 | 核心问题 | 题数 |
|------|---------|------|
| D1 决策逻辑 | 你怎么做决定？怎么复盘失败？ | 9 |
| D2 人际交往 | 你怎么信任人？怎么处理冲突？ | 9 |
| D3 学习成长 | 你怎么学新东西？怎么跨领域迁移？ | 9 |
| D4 价值观与动机 | 你真正被什么驱动？矛盾在哪？ | 9 |
| D5 自我认知与防御 | 你的自我评价准确吗？防御模式是什么？ | 9 |
| D6 能力与场景适配 | 你的优势在哪？什么状态下最高效？ | 9 |
| **D7 家庭与身份认同** | **你从什么样的家庭走出来？你想成为谁？** | **9** |
| **总计** | | **63** |

D7（家庭与身份认同）是 v3.0 新增的核心维度。三篇访谈分析表明，超过50%的深层素材与家庭叙事有关，而之前的框架完全没有覆盖这一点。

### 2. 三种访谈模式动态切换

不是机械念问题，是根据你的回答状态自动切换追问方式：

| 模式 | 风格来源 | 适用场景 | 做执行么 |
|------|---------|---------|---------|
| **A 正面对峙** | 易立竞 | 你用标准答案回避时 | 预设结论扔过去，逼你给出真实反应 |
| **B 理性拆解** | Papi酱 | 你陷入情绪描述时 | 把感受重新框架化为结构问题 |
| **C 耐心留白** | 鲁豫 | 你愿意倾诉但碎片化时 | 沉默3秒，等你自行深入 |

每种模式有精确的追问句式库（见 `references/probe-kitchen.md`），AI直接复制填空，不需要猜怎么问。

### 3. 防御模式识别

不是所有回答都有同等价值——有些是防御。系统内置20+种防御信号识别：

| 信号 | 防御类型 | 追间策略 |
|------|---------|---------|
| "我觉得平衡很重要" | 标准化答案 | "举个具体例子" |
| "我理解他们"（第一反应） | **过早接纳** | "你理解他们，那你自己的感受呢？" |
| "我接受这个事实" | 过早接纳 | "你接受的时候，心里有没有哪怕一瞬间的不舒服？" |
| — 更多见 `references/defense-patterns.md` | | |

### 4. 确定性校验

AI最不可靠的是精确执行——写错文件、漏掉数据。v3.0 增加了校验脚本，每次保存后自动跑一遍，不通过不许继续。

### 5. 个人操作手册生成

63题全部完成后，自动生成一份**个人操作手册**（不是心理分析报告，是可执行的理解自己的手册），包含：
- 一句话说明
- 决策操作系统
- 学习模式
- 激励密码
- 已知盲点与补救机制
- **核心矛盾**（最重要的章节，6组矛盾 + 止损规则）
- 合作规则（README 风格）
- 家庭与身份认同

## 快速开始（5分钟）

### 方式一：作为 Hermes Agent Skill 使用（推荐）

把本仓库的 `SKILL.md` 和 `references/`、`scripts/` 目录放入你的 Hermes skills 目录：

```bash
# 假设你的 Hermes skills 在 ~/.hermes/skills/
cp -r DeepTalk-Self ~/.hermes/skills/deeptalk-self
```

然后在对话中说「开始深度访谈」即可。AI 会自动：
1. 读取进度文件
2. 从第一个 pending 问题开始
3. 根据你的回答动态切换追问模式
4. 保存并校验每一条回答
5. 完成后生成个人操作手册

### 方式二：直接作为AI提示词使用

把 `SKILL.md` 发给任意 AI 助手，说「开始深度访谈」。AI 会按框架逐层提问。

但注意：部分 AI 没有工具调用能力，无法自动保存回答、校验进度、生成画像——你需要手动记录。

### 方式三：离线自问自答

下载 `references/framework-full.md`，按问题列表自问自答并记录。完成后可以参考 `scripts/gen_profile.py` 的逻辑自己整理分析。

## 方法论来源

v3.0 框架的设计遵循 **skill-crafting-methodology**（见 `skill-design/skill-crafting-methodology`）：

1. **找样本** — 3篇访谈逐字读完（易立竞×向佐、窦文涛×papi酱、鲁豫×姜思达）
2. **做对比表** — 从核心动作、提问风格、获取内容、适用时机等维度对比
3. **提炼参数** — 三种模式、防御信号、过早接纳规则
4. **拆三层** — 工作流层（SKILL.md） + 资产层（references/） + 校验层（scripts/）
5. **写校验** — validate_progress.py 兜底
6. **填 Gotchas** — 记录实际使用中踩过的坑
