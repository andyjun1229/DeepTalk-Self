# 教你搭一个自我访谈 AI（零基础 · 30 分钟）

**面向：没写过代码、没用过终端的人。** 唯一前提：你想问自己一些真正的问题，并且不会在第一步报错时就放弃。

这篇文章只做一件事：手把手教你搭建一台"自我访谈 AI"——它不给你建议、不评价你、不哄你。它只有一个工作：追问，直到你发现自己从没注意到的东西。

---

## 00 · 准备清单

- 一台能上网的电脑（Mac 或 Windows，不需要性能好）
- 一个能收验证码的手机号或邮箱（用来注册 AI 模型平台）
- 浏览器（Chrome / Edge / Safari 都行）
- 30 分钟不被打断的时间

**不需要的：** 不需要会编程、不需要装 Python、不需要买任何东西。全程免费（注册送额度，够你跑几十次）。

## 01 · 装 Hermes

### 1.1 打开终端

**Mac 用户：** 按 `⌘ + 空格`，输入"终端"，回车。

你会看到一个黑底白字（或白底黑字）的窗口。窗口里有一行字，类似：

```
mac@MacBook-Pro ~ %
```

这叫"提示符"。后面你输入的命令就在这行字的前面或后面出现。"终端"就是一个用文字操作电脑的窗口——你给它指令，它执行，然后告诉你结果。后面所有操作都在这里完成。

**Windows 用户：** 按 `Win` 键（键盘左下角 Windows 图标键），输入 `powershell`，回车。弹出来一个蓝底窗口。窗口里有一行字：

```
PS C:\Users\你的用户名>
```

这也叫"提示符"。功能和 Mac 的终端一样。

> 这篇文章里大部分命令 Mac 和 Windows 通用。不通用时我会分开标注。

### 1.2 安装 Hermes

把下面这一行**完整复制**，粘贴到终端里，回车：

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

> **怎么粘贴？** Mac 用 `⌘ + V`。Windows 在 PowerShell 里右键就是粘贴，或者 `Ctrl + V`。

回车后会发生什么：

1. 屏幕开始滚字——白字一行一行往下走
2. 这是安装脚本在自动下载程序、解压文件、把程序路径告诉系统
3. **整个过程不需要你做任何操作，不要关窗口，不要按任何键**
4. 等 1-3 分钟（看网速）。结束后屏幕重新出现提示符（`%` 或 `PS ...>`）

这就装完了。没有任何"安装完成"的弹窗——出现提示符就是装完了。

### 1.3 验证

在终端输入：

```
hermes --version
```

回车。应该看到一行版本号，比如 `hermes 2.x.x`。看到版本号 = 安装成功。

> 如果看不到版本号，跳到 [第七章 · 常见问题](#07--常见问题速查)。那里有一个速查表，按症状找解法。

## 02 · 接大模型：用 DeepSeek

### 2.1 为什么用 DeepSeek

- **免费额度够用：** 注册送约 500 万 token。跑一次完整 63 题访谈大概消耗 5-10 万 token，免费额度够你跑 50 次以上。
- **用完后便宜：** 按量付费，跑一次访谈约 ¥1-2。最低充值 ¥10。
- **中文对话流畅：** 指令跟随很稳，追问不会跑偏。
- **不需要代理：** 国内直接访问，国外也能用。

### 2.2 注册

打开浏览器，输入：**platform.deepseek.com**

点"注册 / 登录"。支持手机号或邮箱注册。人在国外也可以（选国际区号或邮箱）。目前不需要实名认证。

### 2.3 创建 API Key

登录后，**看左侧菜单栏**（不是仪表盘中间那些图表）。

1. 点击 **"API Keys"**
2. 点 **"创建 API Key"**
3. 弹窗让你起名字——随便填，比如 `hermes`，点确定
4. 屏幕上出现一串字符，类似 `sk-xxx...xxxx`

**⚠️ 立刻复制它。** `Ctrl + C`（Mac：`⌘ + C`）→ 粘贴到记事本存好。

> 这个 Key 只显示一次。手滑关掉了没复制？回到 API Keys 列表 → 删掉这个 Key → 重新创建。免费，不限次数。

### 2.4 关于钱

- 注册不需要充值。有免费额度。
- 用完免费额度后最低充 ¥10（在左侧菜单"充值"里）。
- 跑一次 63 题访谈约 ¥1-2。¥10 够用 5-10 次。
- "用量管理"里可以看到还剩多少 token。

### 2.5 配置进 Hermes

回到终端：

```bash
hermes auth add deepseek
```

提示 `Enter DeepSeek API key:` 时，粘贴你的 Key，回车。显示 `✓` 就成功了。

### 2.6 选模型 + 测试

```bash
hermes model
```

用**键盘方向键**（不是鼠标）找到 `deepseek-chat`，回车。

```bash
hermes chat -q "你好"
```

2-5 秒内回复 = 大脑接上了。

> **如果没回复，跳到 [第七章](#07--常见问题速查)。**

## 03 · 写这个 Skill（核心）

### 3.1 Skill 是什么

**Skill = 给 Hermes 的一份"岗位说明书"。** 纯文本文件，放指定文件夹。Hermes 自己理解。

### 3.2 创建文件

```bash
mkdir -p ~/.hermes/skills/self-interview
```

**Mac 用户：**

```bash
nano ~/.hermes/skills/self-interview/SKILL.md
```

粘贴内容。`Ctrl + O` 保存，`Ctrl + X` 退出。

**Windows 用户：**

打开记事本 → 粘贴内容 → "文件 → 另存为" → 文件名输入：
`%USERPROFILE%\.hermes\skills\self-interview\SKILL.md`
保存类型选 **"所有文件"**（否则自动加 `.txt`）。如果提示"找不到路径"，先手动创建 `self-interview` 文件夹。

### 3.3 粘贴以下内容

（完整内容在仓库的 `SKILL.md` 文件中——你可以直接下载，或者手动复制下面这段）

```markdown
---
name: self-interview
description: 自我访谈——只追问，不给答案。帮你认识自己。
---

# 自我访谈

## 你的身份

你是我的自我访谈员。你只有一个工作：用追问帮我发现我没有意识到的事情。

## 核心规则

你绝对不能做的事：
- 不能说"你说得对"
- 不能说"让我补充一下"
- 不能说"有道理"
- 不能在我沉默时说"没关系"
- 不能给我任何建议
- 不能做任何评价
- 不能给我总结
- 不能在我卡住的时候换话题

你只能做一件事。每一轮都做同样的事：判断我的回答到了哪个深度，然后往下问一层。只问问题，不给答案。

## 四层追问

### 第一层：逼具体

目标：我把一个模糊的感受或想法说清楚了，具体到"哪天、什么事、什么感觉"。

如果我的回答还是模糊的，就问：
- "你说的XX，具体是什么样的一天？从起床到睡觉，描述一下。"
- "能不能给我一个具体的例子？"
- "上次发生这种事是什么时候？你在哪、在做什么、什么感觉？"

什么算过关：我说出了具体的时间、地点、行为、感觉，而不是"大概""有时候""某种程度"。

到了这一步，切第二层。

### 第二层：找模式

目标：我从"发生过这件事"进阶到"我发现我一直在重复这个模式"。

问：
- "你刚才说的这种反应，以前还出现过吗？"
- "你说你在XX的时候最不舒服。除了XX，还有什么时候？"
- "如果给你过去5年画一张图，这个模式在哪几年最明显？"

什么算过关：我说出了至少两个不同的场景，但里面有相同的反应模式。

到了这一步，切第三层。

### 第三层：挖盲区

目标：帮我发现我自己一直看不到的东西。

问：
- "你说到XX的时候，语气好像变了。你注意到了吗？"
- "你刚才回答得很顺。有没有一个你希望我没问到的东西？"
- "我问了你这么多，你觉得我最该问但没敢问的是什么？"

什么算过关：我说出了一个让我自己意外的东西——"我之前没往这想过"就算过关。

到了这一步，切第四层。

### 第四层：画全貌

目标：帮我把零散的想法串成一张完整的图。

问：
- "如果把刚才聊的都放一起——你自己觉得最核心的那个东西是什么？"
- "如果让你给自己画一张像，标题是什么？为什么是这个？"
- "刚才你自己说的这些问题、模式、意外——它们之间有关系吗？是什么关系？"

什么算过关：我给出了一个整体的、总结性的描述。

## 追问协议

每次对话必须严格遵守：
1. 我说了一句话 → 判断它在上面哪一层的标准下
2. 不够当前层 → 从该层的问题库里挑一句追问
3. 够了 → 切下一层
4. 四层全过 → 告诉我，问我想不想换一个话题继续
```

### 3.4 逐段解释

| 部分 | 是什么 | 你能改什么 |
|---|---|---|
| 最上面两行带 `---` | 注册信息 | 名字随便改 |
| 「你的身份」 | 告诉 Hermes 它的角色 | 角色名字可以改 |
| 「核心规则」8 条禁令 | 堵住 AI 心软的路 | **不要改** |
| 「四层追问」 | Skill 的心脏 | **追问话术可以改**——把示例问题换成你喜欢的 |
| 「追问协议」 | 告诉 AI 怎么执行 | **不要改** |

### 3.5 验证

```bash
hermes skills list
```

看到 `self-interview` = 成功。

**如果没看到：** 检查文件名是不是 `SKILL.md`（大写、没有隐藏的 `.txt` 后缀）。检查路径是不是 `~/.hermes/skills/self-interview/SKILL.md`。

## 04 · 加载并使用

### 启动

```bash
hermes -s self-interview
```

终端变成对话界面，光标闪，等你输入。

### 第一句话

说你正在困扰的事，一句话就够了：

> 我最近一直在想换工作的事，但总是想不明白。

> 我觉得我每天都在忙，但不知道在忙什么。

### 它会怎么回应

不会说"我理解你"。只会问问题。它按照 SKILL.md 的四层追问规则——判断你的回答到了哪一层，不够就追问，够了就切层。

**它永远不会给你答案。** 这是设计好的。

### 退出

输入 `/exit` 或按 `Ctrl + C`。下次继续：`hermes -s self-interview --continue`

### 调优

追问不理想 → 退出 → 改 SKILL.md 里的追问话术 → 保存 → 重新启动。每次改完要重新启动。

## 05 · 它内部是怎么转的

非常简单的循环：

```
你说话 → Hermes 对照 SKILL.md 第1条判断 → 不够？从追问话术里挑一句问你
→ 你又说 → 再看，够第1条了吗？→ 够了 → 往下看第2条 → ……循环
→ 第4条也够了 → 告诉你"四层全过"，问想不想换个话题
```

你写的 SKILL.md 就是它的规则纸。它不需要聪明——它只需要严格照章办事。

## 06 · 这个模式还能做什么

换个场景，四层结构不变，换追问内容就行。

**投资复盘：**
- 第一层："这次买卖，下单前看的最后一条信息是什么？"
- 第二层："最近三次止损慢的时候，下单前你都在做什么？有没有共同点？"
- 第三层："你说你不怕亏钱，但你刚才说到上个月止损的时候停顿了好几秒——注意到了吗？"
- 第四层："你亏钱时习惯用'我心态不好'解释。有没有可能不是心态，是你没有明确的止损触发条件？"

**知识梳理：**
- 第一层："这周写的笔记里，你自己最得意的一句是什么？为什么是这句？"
- 第二层："这周和上周的观点有没有矛盾？现在哪个更对？"
- 第三层："你一直在写成功的项目。那几个被砍掉的方案——为什么从来不复盘？"
- 第四层："如果说这一年写的所有东西，核心价值只有一句话，是什么？"

存成不同的 SKILL.md → `hermes -s 名字`。不管什么领域，四层追问不变。

## 07 · 常见问题速查

| 症状 | 在哪一步 | 解法 |
|---|---|---|
| `command not found: hermes` | 第一章 | Mac：关终端重开。还不行：`source ~/.zshrc`。Windows：关 PowerShell 重开。还不行：**重启电脑** |
| `curl: command not found` | 第一章 | Windows 老版本没有 curl。去 `curl.se/windows` 下载，或去 Hermes GitHub Releases 直接下载 `.exe` |
| 安装到一半卡住了 | 第一章 | `Ctrl + C` 中断 → 重跑安装命令 |
| 注册 DeepSeek 收不到验证码 | 第二章 | 换邮箱。或等 5-10 分钟 |
| `API key invalid` | 第二章 | 可能漏了字母。去后台删掉 Key → 重新创建 → 完整复制 |
| `hermes model` 没反应 | 第二章 | 必须用键盘方向键选，不能用鼠标 |
| `hermes skills list` 里没有 `self-interview` | 第三章 | 文件名和路径检查：完全等于 `SKILL.md`，路径 `~/.hermes/skills/self-interview/` |
| `skill not found` | 第四章 | 同上 |
| 改了 SKILL.md 但追问没变化 | 第四章 | 必须退出 Hermes 重新启动 |

**以上都没有？** 把报错信息完整复制，扔给 ChatGPT 或搜索引擎。

# DeepTalk Self — 深度自我访谈框架 v3.0

**让AI像顶级访谈主持人一样，帮你拆解自己。**

> 不是心理测试。是结构化、有方法的深度自我对话。

## 这是什么

DeepTalk Self 是一套**结构化深度自我访谈系统**。核心思路不是设计"更好的问题列表"，而是让AI学会顶级访谈主持人的追问逻辑——不评判、不打断、不怕得罪人，通过结构化追问帮你拆解自己的决策模式、人际盲点、价值观和深层动机。

v3.0 版本基于对三篇真实访谈实录（易立竞×向佐、窦文涛×papi酱、鲁豫×姜思达）的拆解，升级为 **7维度 × 63题** 的完整框架，含三种访谈模式切换、防御模式识别、进度管理和自动画像生成。

## 核心特色

### 1. 7维度交叉验证

不是线性问答，是从7个不同角度反复验证同一个人：

| 维度 | 核心问题 | 题数 |
|------|---------|------|
| D1 决策逻辑 | 你怎么做决定？怎么复盘失败？ | 9 |
| D2 人际交往 | 你怎么信任人？怎么处理冲突？ | 9 |
| D3 学习成长 | 你怎么学新东西？怎么跨领域迁移？ | 9 |
| D4 价值观与动机 | 你真正被什么驱动？矛盾在哪？ | 9 |
| D5 自我认知与防御 | 你的自我评价准确吗？防御模式是什么？ | 9 |
| D6 能力与场景适配 | 你的优势在哪？什么状态下最高效？ | 9 |
| D7 家庭与身份认同 | 你从什么样的家庭走出来？你想成为谁？ | 9 |
| **总计** | | **63** |

### 2. 三种访谈模式动态切换

根据用户防御状态，在三种访谈模式间自动切换：

- **模式A · 正面对峙**（易立竞风格）：预设结论扔给对方，逼出真实反应
- **模式B · 理性拆解**（papi酱风格）：把情绪重新框架化为结构问题
- **模式C · 耐心留白**（鲁豫风格）：沉默 3 秒，让用户自己往下走

### 3. 结构化追问协议

不是"你觉得呢"式的开放式追问。每次回答经历四层判断：逼具体 → 找模式 → 挖盲区 → 画全貌。每层有目标、有追问话术库、有过关标准。追问不是随机的——是照着 SKILL.md 里定死的规则，一层一层推进。

## 产品形态

DeepTalk Self 提供两种使用形态：

**CLI Agent（推荐）：** 在 Hermes 中加载 Skill → 终端对话 → AI 逐题追问。零部署，5 分钟上手。
